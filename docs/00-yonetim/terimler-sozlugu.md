# Terimler Sözlüğü

> **Durum:** TASLAK  
> **Araştırma tarihi:** 12 Kasım 2026  
> **Kapsam notu:** İlk masa başı araştırma sürümü; hukukçu ve gerçek bilirkişi doğrulaması gerektirir.

| Terim | Açıklama |
|---|---|
| Bilirkişi | Uzmanlık, özel veya teknik bilgi gerektiren konuda sözlü/yazılı oy ve görüş bildirmesi istenen kişi veya özel hukuk tüzel kişisi. |
| Bilirkişilik sicili | Bilirkişiliğe kabul edilen kişilere ilişkin resmî sicil. Sicil ve bölge listesi kavramlarının hukuki ayrıntısı ayrıca doğrulanmalıdır. |
| Bölge kurulu/listesi | Bölgesel bilirkişilik kurulu ve onun hazırladığı liste. |
| Görevlendirme | Yetkili merciin belirli soru, kapsam ve süreyle bilirkişiden inceleme/rapor istemesi. |
| UYAP | Ulusal Yargı Ağı Bilişim Sistemi; yargı süreçlerinin resmî bilişim altyapısı. |
| Bilirkişi Portalı | Bilirkişinin UYAP içinde dosyasıyla ilgili işlemlerini takip etmesini sağlayan portal. |
| Orijinal materyal | İnceleme için teslim alınan kaynak kayıt/medya; üzerinde işlem yapılmaması hedeflenir. |
| Çalışma kopyası | İnceleme/işleme için orijinalden türetilen ayrı kopya. |
| Hash/kriptografik özet | Dosya baytlarının özetini hesaplayan, daha sonraki bütünlük karşılaştırmasına yardımcı değer. Tek başına delil zinciri veya hukuka uygunluk kanıtı değildir. |
| ASR | Automatic Speech Recognition; otomatik konuşma tanıma/transkripsiyon. |
| VAD | Voice Activity Detection; konuşma etkinliği tespiti. |
| WER/CER | Word/Character Error Rate; kelime/karakter hata oranı. |
| DPIA/VERBİS | Bu belgede hukuki bağlamı ayrıca teyit edilmesi gereken veri koruma etki değerlendirmesi ve veri sorumluları sicili kavramları. |
| RTO/RPO | Kurtarma süresi hedefi / kurtarma noktası hedefi. |
| MVP | Minimum Viable Product; asgari doğrulanabilir ürün. |
| ADR | Architecture Decision Record; mimari karar kaydı.
